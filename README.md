# MikroTik Network Labs

A collection of MikroTik RouterOS networking labs, configuration examples, and technical documentation.

## About This Repository

This repository documents practical networking experiments and learning materials using MikroTik RouterOS.

## Topics

- VLAN and Network Segmentation
- Static Routing and Dynamic Routing
- Firewall Filter and NAT
- IPv4 and IPv6
- PPPoE and VPN
- Network Monitoring
- Network Security

## Repository Structure

Lab documentation and configuration examples will be added progressively.

## Security Notice

All examples are intended for educational and laboratory purposes.

No real customer information, production credentials, private keys, or confidential ISP configurations are published.
